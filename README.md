#### I'm a developer and a tech enthusiast who loves building things and spreading what little knowledge I have.

I used to run Packetcode, a YouTube channel where I taught programming languages and their concepts in the easiest way possible. After all...

> “If you can't explain it to a six-year-old, you don't understand it yourself.” - Albert Einstein

#### Some things I've built

- [Brevify](https://github.com/kamaltejag/brevify), a URL shortener in Spring Boot with Redis in front of PostgreSQL and Kafka carrying click events off the redirect path.
- [Plamaco](https://plamaco.com/), a pantry-tracking app I built end to end with AI coding tools. It's live on the App Store.
- A bunch of older experiments from college that are still lying around in my repos.
